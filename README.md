# Loan Default Risk Analysis (EDA) :- 

This project performs **Exploratory Data Analysis (EDA)** on a loan dataset to identify key factors that influence customer loan default risk. The analysis helps understand patterns in customer behavior and supports data-driven credit risk assessment.

## Project Overview :- 
Financial institutions face significant risk when borrowers fail to repay loans. This project analyzes a loan dataset to explore relationships between customer attributes and default behavior.

The goal is to uncover patterns and generate insights that could help banks make better lending decisions.

## Objectives :- 
- Understand the structure of the dataset
- Clean and preprocess the data
- Identify data imbalance in loan defaults
- Perform univariate and bivariate analysis
- Analyze correlations between variables
- Extract insights related to default risk

## Analysis Steps :- 
**1. Data Cleaning**  
   - Handling missing values  
   - Removing inconsistencies  

**2. Data Imbalance Analysis**  
   - Examining the distribution of default vs non-default cases  

**3. Univariate Analysis**  
   - Understanding individual variable distributions  

**4. Bivariate Analysis**  
   - Exploring relationships between variables and loan default  

**5. Correlation Analysis**  
   - Identifying variables strongly related to default risk  

## Technologies Used :- 
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights :- 
- Certain customer and financial attributes strongly influence default probability.
- Data imbalance is present in loan default cases.
- Some features show stronger correlation with default risk and can be useful for predictive modeling.
